# Code Review Checklist

Проходится на каждом шаге перед коммитом. Пункт, который к шагу не относится, пропускается.

## Процесс

- [ ] Все пункты DoD шага из `docs/ROADMAP.md` выполнены.
- [ ] Изменения не выходят за рамки шага (нет «заодно сделал» из следующих шагов).
- [ ] Новых npm-пакетов нет или они согласованы и внесены в `AGENTS.md`.
- [ ] `npm run typecheck`, `npm run lint`, `npm test` зелёные.

## Типы и код

- [ ] Нет `any` (явного и неявного), нет `@ts-ignore` без комментария-обоснования.
- [ ] Внешние данные (env, тело запроса, параметры, ответы из сети) валидируются схемой.
- [ ] Нет `console.*`; логи через pino, с контекстом (`eventId`, `endpointId`, `reqId`).
- [ ] `process.env` встречается только в `src/config`.
- [ ] `app` и `worker` не импортируют модули друг друга.

## Ошибки и надёжность

- [ ] Ошибки не глотаются: обработаны или залогированы и проброшены.
- [ ] Ответы об ошибках в едином формате `{ error: { code, message } }`, без стек-трейсов наружу.
- [ ] У сетевых вызовов есть таймауты.
- [ ] Ресурсы (пул БД, Redis, воркер) закрываются при остановке.
- [ ] Смена статусов — атомарным `UPDATE … WHERE status IN (…)`, без «прочитал → записал».

## База данных

- [ ] SQL только параметризованный.
- [ ] Изменения схемы — новой миграцией с рабочим `down`; применённые миграции не тронуты.
- [ ] Запросы по большим таблицам используют индексы; выборки ограничены `LIMIT`.
- [ ] Связанные записи меняются в одной транзакции.

## Безопасность

- [ ] Секреты не попадают в логи и ответы API.
- [ ] Подписи и ключи сравниваются через `timingSafeEqual` с проверкой длины.
- [ ] Ограничены размеры: тело запроса, тело ответа получателя, страницы списков.
- [ ] Ответы 401/403 не раскрывают причину отказа (причина — только в логе).

## Тесты

- [ ] Новая логика покрыта тестами: unit для чистых функций, integration для БД/очередей/HTTP.
- [ ] Проверены граничные и ошибочные случаи, а не только успешный путь.
- [ ] Тесты не зависят от порядка запуска и не трогают рабочую БД.

## Документация

- [ ] Новые переменные — в `.env.example` и `DEPLOYMENT.md`.
- [ ] Новые команды, сервисы, эндпоинты — в `DEPLOYMENT.md` / `README.md`.
- [ ] Чекбоксы DoD шага отмечены в `docs/ROADMAP.md`.
